# 织忆圣所 0.10.8 候选版本审查说明

审查基线为上游 `v0.10.7`（`a9e7a78`），目标分支为 `passionsugar/silksong-godhome:main`。本文记录个人测试版 `0.10.7.1` 至 `0.10.7.13` 最终保留的改动。正式版本号、合入目标分支后的构建和实机结果，在提审时确认。

## 一、连战编排

前四门共 45 场。单门在下表两列之间休息一次。五门串联四门，并在第一门对应的第 1、3、6 场分别换成织巢双苔母、入侵骸底镇的颅骨暴君、远野二见兽蝇。五门第 6、12、18、24、30、35、40 场后休息，第 45 场为失心蕾丝。

| 门 | 休息前，按出场顺序 | 休息后，按出场顺序 |
|---|---|---|
| 一门，12 场 | 苔藓之母（初遇）、钟道兽、颅骨暴君、第四圣咏团、蕾丝（初遇）、残暴的兽蝇（野兽教堂） | 巨型螺蝇、荒沼翼主、碎裂者长姊、黑寡妇、幽影、末代裁决者 |
| 二门，12 场 | 加蒙德与扎扎、机枢舞者、特罗比奥、伏特维姆、失格大厨卢戈利、机枢击钹者 | 生质异化的赞戈、鸦虫教父、育母、狂暴的螺蝇、伟大的格洛、监工兄弟西格尼斯与格隆 |
| 三门，11 场 | 噬钟者、被放逐的格尔、炽焰之父、边陲守望者、失缚怨魂、沙克拉 | 次席戍卫、针姬、原初罪者、蕾丝（高塔）、崇高圣母灵丝 |
| 四门，10 场 | 蒙召救主、失心加蒙德、痛苦的特罗比奥、苍白苜鹿、圣所守卫者赛斯 | 三叶草舞者、尼莱斯、壳王卡汗、卡梅丽塔、失心蕾丝 |

机枢击钹者沿用手办屋已有战斗，在五门为第 18 场。各门沿用原有 ID、解锁条件、通关记录与最佳时间，旧纪录对应的是当时的路线。配置见 [pantheons.json](../data/pantheons.json)。

## 二、连战资源与束缚

| 项目 | 玩家可观察的行为 |
|---|---|
| 织针锁 | 进入连战时将实际织针等级限制为 `min(原等级, 2)`。满级普通针击的基础伤害由 21 变为 13，并使用敌人对二级针的受伤系数。依赖针等级的丝技随之调整，按制作套件结算的工具仍取套件等级。开门前记录原等级，休息与换场后重施束缚。通关、死亡、放弃或回标题时释放，战斗中存档使用大厅快照。 |
| 灵丝锁 | 丝上限为 9。普通缚丝回 2 格，多重缚丝器第一段回 1 格、第二段回 2 格，两段之间被打断只回复 1 格。兽类和巫类纹章的命中回血上限为 2 格，多重缚丝器生效时为 3 格。工具锁生效时，多重缚丝器随工具停用。 |
| 工具与配装 | 每场胜利携带实际剩余工具次数和药液储备，包含记忆战独立计数。到达休息房时，把已解锁且能自动补给的工具补到本次容量，包括未装备的工具。回大厅时恢复开门前的快照。 |
| 休息点 | 到达时补满血和工具，带入上一战剩余的丝。坐稳后清除蛆水，风灵谣逐格回丝，起身停止，受丝上限约束。前作温泉补接回丝音画，本作备用休息房使用原版长椅效果。下一战继承离座时的血、丝和蓝血。两类休息椅均禁止登记复活点。 |

织忆满配表补入风灵谣解锁标记，已有织忆档读档时补齐。束缚菜单和中英文文本同步更新。配置由 `needleCap`、`needleLowerPercent` 改用 `needleMaxLevel`，默认 2，可取 0–4。实现见 [Bindings.cs](../src/Godhome/Mode/Bindings.cs)、[RunToolSupply.cs](../src/Godhome/Mode/RunToolSupply.cs)、[PantheonRestBench.cs](../src/Godhome/Mode/PantheonRestBench.cs)。

## 四、战场、入场与判胜

| 场景 | 具体改动 |
|---|---|
| 远野二见兽蝇 | 先关闭宿主场景中与战场重叠的六块地板，使下砸能打碎战场自己的岩浆平台。左右和上方加入只挡玩家的边界，底部保留坠落。 |
| 第四圣咏团、失缚怨魂 | 第四圣咏团使用同类三面边界。失缚怨魂保留取钥匙前置，挑战时关闭右侧舱门，并清除本场景覆盖中的旧开门记录。 |
| 加蒙德与扎扎、噬钟者 | 根据加蒙德已到达的骑行或就位状态继续切磋，避免错过等待目标后空等约 15 秒。噬钟者在玩家就位后接收原生开场事件。 |
| 入场点 | 噬钟者改为 `(138.75, 8)`，针姬为 `(32, 87.4)`，两处朝右。失心加蒙德为 `(29.5, 62)`，朝左。失心蕾丝为 `(41.6, 8)`，位于背景丝母与蕾丝出场点之间。 |
| 开场演出与手动挑战 | 原初罪者、失心蕾丝的固定开场动作持有输入锁，演出结束或离场时释放。崇高圣母灵丝、卡梅丽塔在玩家就位后自动接受挑战。灵丝切镜期间锁定输入，卡梅丽塔沿用跳过猎手波次的路线。 |
| 入场后无法操作 | 针对织忆战场入口清理上一场遗留的移动状态。落地且演出交还控制后，若仍不能输入则恢复操作。暂停、交互或其他组件持有输入锁时继续尊重该状态。 |

战场配置增加实例血量、玩家边界、动作前排、已推进状态跳过等待、演出输入锁和单次 HP 比较覆盖。带变量的 HP 比较仅替换指定状态的操作数。配置语义见 [arena.md](arena.md)，应用时机见 [Arena.cs](../src/Godhome/Mode/Arena.cs)。

## 五、大厅、手办屋与存档

- **温泉出口与转场声音。** 将温泉右门指向当前路线已选好的下一战及入口，修复走入黑区。普通胜利、Boss 自行切场时，胜利铃声跨场播完，同一次离场播放一次。走出温泉时仅保留转场画面，最后一战沿用专用结算。
- **屋顶捷径与大厅长椅。** 针击可启动屋顶机关并放下实体平台。每个织忆槽分别保存捷径状态及最近坐过的前厅、屋顶或手办屋长椅，读档时直接选择对应入口。原生存档保存本作可识别的长椅。旧档缺少长椅记录时进前厅，缺少前作场景时回织忆圣所。新增数据字段为 `HubBenchScene`、`RoofShortcutOpened`。
- **43 个展位重新布局。** 下层 22、上层 21，统一为独立底座。挑战提示、拉杆、相机范围、回程门及死亡返回点跟随展位。主形态和备用形态各自渲染，并按同一底座顶面对齐。巨蚤、崇高圣母灵丝在上层末端。原版 0.10.7 已拆开不同 Boss 共用的雕像，本次调整的是布局、可达性和换形显示。
- **回程交互和进屋黑屏。** 回到雕像前，落地且恢复交互后立即重新开放该尊雕像的挑战提示。进屋时先显示房间和可用图鉴立绘，分帧生成并逐尊替换石像。离场取消本次生成，回程可复用已完成的形态。玩家已恢复操作但遮罩仍未退出时补发淡入。
- **跨启动石像缓存。** 已生成图像逐张保存到 `BepInEx/cache/Godhome/statues/`。下次启动后台读取并校验，分帧还原贴图、轴心和像素密度。全命中可跳过雕刻和专用动作帧包加载。按游戏构建、色彩空间、缓存格式及深浅石料区分，单张缺失或校验失败时重新生成。缓存独立于存档，可通过日志中的 `disk hits`、`statues carved` 对比冷、热启动。
- **存档选择界面。** 依据各槽自己的 `BossRushMode` 标记显示本地化模式名与原生织者圣所背景，修复位置标题显示占位符的问题，保留面具、丝轴和游玩时长。

大厅入口和交互见 [Hk1Lobby.cs](../src/Godhome/Hk1/Hk1Lobby.cs)，展位与缓存见 [Hk1Hall.cs](../src/Godhome/Hk1/Hk1Hall.cs)、[StatueDiskCache.cs](../src/Godhome/Mode/StatueDiskCache.cs)。手办屋巡视增加展位数量、备用立绘及实际换形可见性检查。连战自检改为碰撞温泉右门，并核对各场、休息点、存档快照和回大厅后的针等级。

## 六、已撤回方案与验证范围

0.10.7.7 的刀光与落石命中图集修补已撤回。0.10.7.12 的幽影额外选招检查和延迟判胜已撤回，最终采用半血判定。建筑师与萨满在工具锁下的平衡仍属讨论项。旧的 44 场路线和按四级受伤系数估算织针锁的提案数据仅代表当时的方案。

| 已有证据 | 合入开发分支后优先实测 |
|---|---|
| 玩家已在早期测试包确认温泉右出口能继续连战。最终数据包含五门全部 45 场与七处休息点。 | 走过第 18 场机枢击钹者后的温泉，从右门进入赞戈，再验证第 35 场后的跨门衔接。 |
| 本地测试版使用已安装的游戏程序集离线编译。最终半血版的检查覆盖 50 个条目、14 场的 17 个生命组件，以及幽影 261、260、259 血的原版比较行为。 | 满级针、二级针各打一次幽影，观察浓雾与归零判胜。另测黑寡妇假死、第四圣咏团打头与落石、监工兄弟单人存活时的回复。 |
| 历轮场景数据检查和离线测试覆盖战场边界、演出输入、资源继承、长椅复活点及存档卡片。 | 在织忆旧档中测试坐温泉后退回标题、针锁下死亡或退出、屋顶捷径及大厅落点。用普通剧情档对照存档卡片、长椅和针等级。 |
| 石像缓存可在进屋完成后统计命中数。 | 完整生成后重启，比较第二次进屋的命中数与卡顿，实测来回开战及切换蕾丝多形态。 |

正式 0.10.8 在作者 `main` 上的 Release 构建、整轮手动连战及缓存耗时，仍待合并候选代码后记录。
