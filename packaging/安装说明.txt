织忆圣所 The Loom of Recollection {VERSION}
《空洞骑士：丝之歌》的 Boss 重温 / 连战模组（BepInEx 5 插件）。非官方粉丝作品。
源码和问题反馈：https://github.com/passionsugar/silksong-godhome

【一键安装（推荐）】
1. 先关掉游戏。把这个压缩包整个解压到一个文件夹（不要在压缩包里直接双击）。
2. 双击 install.bat。它会：
   - 自动找到 Steam 里的《空洞骑士：丝之歌》；找不到会让你粘贴游戏文件夹的路径
     （Steam 里右键游戏 → 管理 → 浏览本地文件，复制地址栏）。
   - 没装 BepInEx 5 的，从 Thunderstore 下载 BepInExPack_Silksong 1.0.3 装进游戏文件夹。
   - 缺前置插件的，从 Thunderstore 下载 DataManager 1.2.2、I18N 1.1.1 放进 BepInEx\plugins。
   - 本机装了《空洞骑士》（前作）的，再装 UnitySceneRepacker 0.3.0（前作神居要用）。
   - 把织忆圣所复制到 BepInEx\plugins\Godhome（旧版本整个换掉）。
   装之前会列出要做的事，按回车开始，输入 n 取消。已经装好的不会重复下载。
3. 看到“全部装好了”就可以开游戏了。第一次装 BepInEx 后，第一次启动会慢一点。
不碰存档，不改游戏原文件，不改配置文件。游戏开着时它不会装。
游戏不是 Steam 版、装在别处的：在这个文件夹里打开 PowerShell，运行
  powershell -ExecutionPolicy Bypass -File install.ps1 -GameDir "游戏文件夹"
用 r2modman 等模组管理器的：不要用 install.bat，见下面“手动安装”。

【需要】
- 正版《空洞骑士：丝之歌》（测试用的游戏版本 1.0.30000）
- BepInEx 5（BepInExPack_Silksong 1.0.3；测试用 BepInEx 5.4.23）
- 两个前置插件（silksong_modding 出的，Thunderstore 上有）：DataManager 1.2.2、I18N 1.1.1
一键安装会自动装上面这些。

【可选：前作神居】
同一台电脑装了《空洞骑士》（前作）时，神居存档的大厅、手办屋、万神殿的门、休息点的温泉、连战转场直接用前作神居的场景。要再装：
- jakobhellermann 的 UnitySceneRepacker 0.3.0（Thunderstore 上有；一键安装找到前作时会自动装）
- 《空洞骑士》本体。Steam 版会自动找到；装在别处的，在 BepInEx\config\local.silksong.godhome.cfg 的 Experimental 一段里把 Hk1GameDir 填成前作的游戏目录。
前作的场景在运行时从你本机的游戏文件里读取。没装前作或者不想用，就用丝之歌素材搭的圣所（配置里 Hk1Godhome = false）。

【手动安装】
先装好 BepInEx 5 和上面两个前置插件，再把压缩包里的 BepInEx 文件夹合并到游戏目录（和 Hollow Knight Silksong.exe 同一层）。
装好以后是：BepInEx\plugins\Godhome\Godhome.dll（旁边有 data、languages 两个文件夹）。
用 r2modman 等管理器的：先在管理器里装好前置，再把 BepInEx\plugins\Godhome 整个文件夹放进那个配置的 BepInEx\plugins。

【开始玩】
主菜单 → 选一个空的存档槽 → “选择模式”里选「织忆圣所」。
这是单独的神居存档：一开始就有全部能力、工具和纹章，重温每一位 Boss、挑战万神殿。普通存档不受影响。
走到 Boss 雕像或万神殿的门前按交互（上），选一档难度开打。
第五个万神殿要先通关前四个才开。
出了问题（例如需要重新读档、场地出错）时，屏幕下方会出现提示框，几秒后自己消失。

【卸载】
双击 uninstall.bat（只删 BepInEx\plugins\Godhome），或者自己删掉这个文件夹。
前置插件和 BepInEx 留着（别的模组可能也在用）。神居存档还在原来的存档槽里，不要了可以在游戏里删掉。

【说明】
- 压缩包里不含任何游戏文件。一键安装只从 thunderstore.io 下载上面列出的前置，并核对包名和版本。
- 调试功能默认关闭，不用管配置文件里 [Debug] 那一段。
- 还没手动实测的：几位 Boss 的入场点离 Boss 很近（进场时可能马上被撞到）；寡妇要按特殊挑战才开打。
- 出问题时请在上面的 GitHub 地址提 issue，附上 BepInEx\LogOutput.log。

The Loom of Recollection {VERSION}
A boss-rush / boss-revisit mod for Hollow Knight: Silksong (BepInEx 5 plugin). Unofficial fan work.
Source and issues: https://github.com/passionsugar/silksong-godhome

One-click install (recommended)
1. Close the game. Extract the whole archive to a folder (do not run it from inside the zip).
2. Double-click install.bat. It will:
   - find Hollow Knight: Silksong in your Steam libraries, or ask you to paste the game folder
     (Steam: right click the game → Manage → Browse local files);
   - install BepInExPack_Silksong 1.0.3 from Thunderstore if BepInEx 5 is missing;
   - install DataManager 1.2.2 and I18N 1.1.1 from Thunderstore into BepInEx\plugins if missing;
   - install UnitySceneRepacker 0.3.0 when Hollow Knight is installed (for Hollow Knight's Godhome);
   - copy the mod to BepInEx\plugins\Godhome (replacing an older version).
   It shows the plan first; press Enter to go on, or type n to cancel. Nothing is downloaded twice.
3. When it says "All done", start the game. The first start after installing BepInEx takes longer.
It never touches your saves, the game's own files or config files, and refuses while the game runs.
Game installed somewhere else / not on Steam: open PowerShell in this folder and run
  powershell -ExecutionPolicy Bypass -File install.ps1 -GameDir "<game folder>"
Using r2modman or another mod manager: don't use install.bat, see "Manual install" below.

Requirements
- Hollow Knight: Silksong (tested on game version 1.0.30000)
- BepInEx 5 (BepInExPack_Silksong 1.0.3; tested with BepInEx 5.4.23)
- Two dependency plugins by silksong_modding (on Thunderstore): DataManager 1.2.2, I18N 1.1.1
The one-click installer installs all of these.

Optional: Hollow Knight's Godhome
If Hollow Knight is installed on the same PC, the lobby, workshop, pantheon doors, rest-stop spa and
pantheon transitions come from the original Godhome scenes. You also need:
- UnitySceneRepacker 0.3.0 by jakobhellermann (on Thunderstore; the installer adds it when it finds
  Hollow Knight)
- Hollow Knight itself. Steam installs are found automatically; otherwise set Hk1GameDir in the
  Experimental section of BepInEx\config\local.silksong.godhome.cfg to the game folder.
The scenes are read at runtime from your own copy of the game. Without it (or with Hk1Godhome = false)
the mod builds its own sanctum from Silksong's assets.

Manual install
Install BepInEx 5 and the two dependencies first, then merge the BepInEx folder from this archive into
the game folder (next to Hollow Knight Silksong.exe). You should end up with
BepInEx\plugins\Godhome\Godhome.dll (plus the data and languages folders).
With r2modman or another manager: install the dependencies there, then copy the whole
BepInEx\plugins\Godhome folder into that profile's BepInEx\plugins.

Play
Main menu → pick an empty save slot → choose "The Loom of Recollection" in the play mode menu.
It is a separate save: every ability, tool and crest from the start; revisit each boss and take on
the pantheons. Your normal saves are not touched.
Walk up to a boss statue or a pantheon door and press interact (up), then pick a difficulty.
The fifth pantheon unlocks after clearing the first four.
When something goes wrong (for example a reload is needed, or an arena failed), a notice box appears
at the bottom of the screen for a few seconds.

Uninstall
Double-click uninstall.bat (removes BepInEx\plugins\Godhome only), or delete that folder yourself.
BepInEx and the dependencies stay (other mods may use them). The save stays in its slot; delete it in
game if you no longer want it.

Notes
- The archive contains no game files. The installer downloads only the dependencies listed above, from
  thunderstore.io, and checks each package's name and version.
- Debug features are off by default; ignore the [Debug] section of the config file.
- Not yet checked by hand: for a few bosses the entry point is very close to the boss; Widow needs
  the special challenge to start.
- If something goes wrong, please open an issue at the GitHub address above and attach
  BepInEx\LogOutput.log.
