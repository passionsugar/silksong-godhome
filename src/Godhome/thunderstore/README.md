# The Loom of Recollection · 织忆圣所

A boss-revisit and pantheon boss-rush mod for *Hollow Knight: Silksong*. Unofficial fan work, not affiliated with Team Cherry.

《空洞骑士：丝之歌》的 Boss 重温 / 万神殿连战模组。非官方粉丝作品，与 Team Cherry 无关。

## Features

- **A separate save**: on the main menu pick an empty save slot, then choose "The Loom of Recollection" in the play mode menu. You start with every ability, tool and crest. Your normal saves are not touched: the mod only changes things inside this save.
- **Boss revisits**: 50 boss fights, entered through a dream gate; you come back to the statue afterwards. Three difficulty tiers.
- **Pantheons**: five pantheons, four bindings (needle, masks, silk, tools), rest stops and a results screen. The fifth pantheon unlocks after the first four.
- **Hollow Knight's Godhome (optional)**: if *Hollow Knight* is installed on the same PC and `jakobhellermann-UnitySceneRepacker` is installed, the lobby and pantheon scenes come from the original Godhome. They are read at runtime from your own copy of the game; this package contains no game files. Without it the mod builds its own sanctum from Silksong's assets.

## Install

Install with a Thunderstore-compatible mod manager (r2modman / Thunderstore Mod Manager); BepInEx, DataManager and I18N are installed as dependencies. Do not also install the GitHub release archive into the same game: use one or the other.

使用 r2modman / Thunderstore Mod Manager 安装，前置（BepInEx、DataManager、I18N）会自动装上。不要再用 GitHub 压缩包往同一个游戏里装一份，二选一。

想用前作神居场景的，另外装 `jakobhellermann-UnitySceneRepacker`，并在同一台电脑装好《空洞骑士》。
